How it works (honest)

Phones connect straight to the host browser over WebRTC (PeerJS) using the free public PeerJS broker. No game server, no accounts. If WebRTC is blocked, it falls back to local mode, where only tabs on the same device can join. Very large crowds (100+) haven't been tested yet.
