Your browser game can earn money.

Arcade Kit adds a sponsor billboard you can sell, a tip button, a local leaderboard, challenge links that dare friends to beat your score, and a "next game" ring that sends players around a network of indie games. No backend and no SDK, and it works with any engine.

▶ Try the demo game⬇ kit.js (≈6 KB)

Install

<!-- paste before </body> -->
<script src="kit.js"
  data-game="My Game" data-venmo="yourhandle"
  data-contact="https://x.com/you" data-ad-price="100"
  data-ring="https://friend1.dev/game,https://friend2.dev/game"></script>

API

const rank = ArcadeKit.submitScore(score);      // saves + toasts "new best" / "you beat the challenge"
ArcadeKit.challengeLink(score);                   // URL that dares a friend to beat it
new THREE.CanvasTexture(ArcadeKit.billboard());  // "your ad here" or your sponsor, as an in-world texture
ArcadeKit.onChallenge(c => showBanner(c.name, c.score));

💸 Sell a slot

The billboard reads "your ad here · $X/mo" and links to your DMs. Once you close a deal, set data-sponsor and it switches over.

⚔️ Challenge links

Your best score goes into a link. When a friend opens it, they get a dare, and a toast when they beat it. Sharing does the marketing for you.

⟳ Game ring

Point data-ring at friends' games. Players hop between them, so everyone in the ring shares traffic.

Honest limits: scores stay on the player's device, and challenge links have a checksum but can be faked. That's fine for friendly dares, not for prize money.
