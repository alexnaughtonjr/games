One script tag.
Scores, dares, a tip.

Arcade Kit hangs a sponsor billboard, a Venmo tip, a leaderboard that stays on the player's device, and a link that dares a friend to beat a score. Play the 30-second demo, then copy the tag.

Paste this

<!-- before </body> -->
<script src="kit.js"
  data-game="My Game" data-venmo="alexnaughtonjr"
  data-contact="https://x.com/alexnaughtonjr" data-ad-price="100"
  data-ring="https://friend.dev/game"></script>
const rank = ArcadeKit.submitScore(score);
ArcadeKit.challengeLink(score);
new THREE.CanvasTexture(ArcadeKit.billboard());

Set the canvas texture color space to sRGB in Three r152+ or the billboard washes out up close. DM a sponsor before anyone pays. The tip button opens Venmo. This page does not charge a card.

Sell a slot

The board says "your ad here" until you set data-sponsor after a real yes.

Challenge links

A checksum in the URL. Fine for a dare between friends, not for prize money.

Game ring

data-ring is a list of other games. Players hop. Everyone shares traffic.
